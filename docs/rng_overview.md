# 真随机数生成器 (RNG)

> RM0436 Chapter 37

## 概述 (pp.1919)

RNG 是一个真随机数生成器，以 32 位样本的形式向应用程序提供全熵输出。它由一个实时熵源（模拟）和一个内部调理组件组成。

RNG 可用作实时熵源，构建符合 NIST 标准的确定性随机比特生成器（DRBG）。

RNG 已通过德国 BSI 的 AIS-31 统计测试（T0 至 T8）。

## 主要特性

- 输出 32 位真随机数，由模拟熵源产生并经高质量调理级处理
- NIST 配置下，每 16× RNG 时钟周期产生 4 个 32 位随机样本（若 AHB 时钟周期数高于 213 个周期，则为每 213 个周期）
- 嵌入式连续基本健康测试及错误管理
- 采样时钟过低检测和重复计数测试
- 可关闭以降低功耗
- AMBA AHB 从设备接口，仅支持 32 位字单次访问（否则产生 AHB 总线错误，写操作被忽略）

## 功能描述

### 随机数生成 (pp.1920-1921)

RNG 通过 AHB 接口以确定的时间间隔输出真正的随机数据。其熵源模型如下：

```
                    Error (HealthTest)
                         ↑
┌──────────┐  ┌───────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│  Noise   │→│Post-proc  │→│Condition │→│  Health  │  │ GetEntropy│
│  Source  │  │(de-bias)  │  │  (AES)   │  │  tests   │  │ (output)  │
└──────────┘  └───────────┘  └──────────┘  └──────────┘  └──────────┘
                                     │
                               Entropy source
```

#### 噪声源 (p.1921)

- 两个模拟噪声源，每个基于**三个 XOR 的自由运行环形振荡器**输出
- 采样级由专用时钟输入 **rng_clk** 驱动，每个周期产生 **2 位**原始数据
- 噪声源采样与 AHB 接口时钟频率 **rng_hclk 无关**（异步）
- 可关闭振荡器以省电

#### 后处理（去偏差）(pp.1921-1922)

原始噪声源输出存在偏差（偏"1"或偏"0"），后处理组件将其降低到可容忍水平：

> 对每一位，**一半取自原始采样值，一半取自取反后的采样值**

如果源产生更多"1"或"0"，就会被过滤掉。

#### 调理（熵浓缩）(p.1922)

调理组件是一个**确定性函数**（基于 AES 类的加密算法），将 128 位原始数据浓缩为**128 位高熵输出**。

- 触发条件：收到至少 **32 位**原始数据且 **FIFO 需要刷新**
- 调理组件由更快的 **AHB 时钟**驱动
- 每次调理完成需要 **213 个 AHB 时钟周期**（或 16 个 rng_clk 周期）

#### 输出缓冲 (p.1922)

- 容量：**4 个 32 位字（128 位）** FIFO
- 通过 **RNG_DR** 寄存器依次读取
- **DRDY** 标志：FIFO 中有数据时置 1，读完 4 个字后清 0
- 读完 4 个字后自动触发下一轮调理
- 使能中断时，DRDY 上升沿触发中断

### 数据流总结

```
rng_clk 每个周期     64 个周期后         触发条件满足时
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────┐
│ 噪声源 → 2bit  │──→│ 原始数据移位  │──→│ 后处理+调理   │──→│ FIFO     │
│ (2 个振荡器)   │   │ 寄存器 128bit │   │ (AES 类算法)  │   │ 4×32bit │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────┘
                                                                    │
                                                              RNG_DR ←┘
                                                              (软件读取)
```

每个 rng_clk 周期产生 2bit → 64 个周期填满 128bit 移位寄存器 → 后处理去偏差 → 调理(AES)提取全熵 → 128bit 推入 FIFO → 软件分 4 次读取 RNG_DR。

### 健康检查 (p.1922)

确保整个熵源（含噪声源）启动并按预期运行。

#### 连续健康测试

在噪声源输出上无限期运行：

| 测试 | 触发条件 |
|------|---------|
| 重复计数（单源） | 一个噪声源连续输出 64 个相同位，或 32 个连续 "01"/"10" 模式 |
| 重复计数（双源） | 两个噪声源都连续输出 32 个相同位，或 16 个连续 "01"/"10" 模式 |

#### 供应商特定连续测试

| 测试 | 触发条件 |
|------|---------|
| 采样时钟过慢检测 | 一个 RNG 时钟周期 < AHB 时钟周期 ÷ 32 |

错误状态记录在 **RNG_SR** 寄存器的 **CECS** / **SECS** 位。检测到错误时可产生中断。

### RNG 初始化 (p.1923, Figure 323)

使能 RNG（RNGEN=1）后的初始化流程：

```
RNGEN=0 → RNGEN=1
       │
       ▼
┌───────────────┐
│ 1. 使能噪声源  │  ← 立即开始采样，填充 128bit 调理移位寄存器
└───────┬───────┘
        ▼
┌───────────────┐
│ 2. 调理硬件初始化│  ← 使用两个 128bit 噪声源位初始化后处理上下文
└───────┬───────┘
        ▼
┌───────────────┐
│ 3. 补充填充    │  ← 再次填充 128bit 输入数据缓冲
│   执行一轮调理  │  ← 输出缓冲填入后处理结果
└───────┬───────┘
        ▼
┌───────────────┐
│ 4. 自动刷新    │  ← 根据 RNG 使用情况自动补充
│   持续输出     │
└───────────────┘
```

初始化时间参数见第 37.5 节。

### RNG 操作 (p.1924)

#### 中断模式

1. 设置 **IE=1**（RNG_CR）使能中断，同时设 **RNGEN=1** 使能 RNG
2. 在中断处理中检查：
   - **无错误**：RNG_SR.SEIS=0 且 CEIS=0
   - **数据就绪**：RNG_SR.DRDY=1
3. 条件满足则读取 RNG_DR（最多连续 4 次），条件不满足则**不可读 RNG_DR**
4. 发生错误时执行错误恢复序列（第 37.3.7 节）

#### 轮询模式

1. 设 **RNGEN=1**（RNG_CR）使能 RNG
2. 轮询 RNG_SR，检查：
   - 无错误（SEIS=0, CEIS=0）
   - 数据就绪（DRDY=1）
3. 条件满足则读取 RNG_DR（最多连续 4 次）
4. 发生错误时执行错误恢复序列

> **注意：** DRDY=0 时读 RNG_DR 返回 0。建议始终验证 RNG_DR 的值不为 0，因为偶发情况下轮询 RNG_SR 到读取 RNG_DR 之间可能出现种子错误（罕见事件）。

#### 软件后处理

如果需要 NIST 批准的安全强度为 128 位的 DRBG，必须在 RNG 真随机数生成器之外构建一个经批准的随机数生成软件。

### RNG 时钟 (pp.1924-1925)

RNG 使用两个不同的时钟：
- **AHB 时钟（rng_hclk）**：用于 AHB 寄存器接口和调理组件
- **RNG 专用时钟（rng_clk）**：用于噪声源采样

时钟约束：
- 当 CED=0（RNG_CR）时，**rng_clk 频率必须高于 rng_hclk 频率 ÷ 32**，否则时钟检查器会报错（CECS=1）
- 推荐时钟配置见第 37.6 节

### 错误管理 (p.1925)

#### 时钟错误检测

| 条件 | 现象 |
|------|------|
| CED=0 且 rng_clk 频率过低 | CEIS=1, CECS=1 |
| 时钟恢复正常 | CECS 自动清 0 |

- 时钟错误**不影响**已生成的随机数，仍可读 RNG_DR
- 处理：检查时钟配置 → 写 0 清除 CEIS 中断标志
- CEIS 仅在 CECS 被硬件置 1 时才置位

#### 种子错误（噪声源错误）检测

当噪声源出错时，RNG **停止生成随机数**，置位 SEIS=1 和 SECS=1。

> 此时 RNG_DR 中的数据**不得使用**（熵不足）。

**初始化期间检测到种子错误：** RNG 自动重新启动整个初始化序列。

**正常运行时种子错误恢复序列：**
1. 写 0 清除 **SEIS** 位
2. 从 RNG_DR 读出 **12 个字**并丢弃（清空流水线）
3. 确认 SEIS 仍然为 0
4. 恢复正常随机数生成

### RNG 低功耗使用 (pp.1925-1926)

当 DRDY=1 后，可立即清 RNGEN=0 关闭 RNG 省电。RNGEN=0 时后处理和输出缓冲仍可工作：

- 若输出缓冲中仍有有效数据 → 仍可从 RNG_DR 读取最多 **4 个**随机数
- 若调理输出内部寄存器仍有有效数据 → 还可额外读取 **4 个**随机数
- 若两者都空了 → 必须重新使能 RNG，等待至少 **16 个 rng_clk 周期**（采样新位）+ **216 个 AHB 时钟周期**（一轮调理）

关闭 RNG 会关闭所有模拟种子生成器（功耗见数据手册电气特性），同时关闭 RNG 时钟域的所有逻辑门控。

> **注意：** 低功耗策略会增加延迟（重新初始化时间）。

**初始化期间关闭：** 如果在 DRDY 第一次置位前关闭 RNG，下次 RNGEN=1 时会从**断点继续**初始化，而不是从头开始。

## RNG 中断 (p.1926, Table 264)

| 中断事件 | 事件标志 | 使能控制位 | 清除方式 |
|---------|---------|-----------|---------|
| 数据就绪 | DRDY | IE | 自动（读数据后硬件清除） |
| 种子错误 | SEIS | IE | 写 0 清除 SEIS |
| 时钟错误 | CEIS | IE | 写 0 清除 CEIS |

- 三种中断共用一根中断线，通过 IE 位统一使能
- 仅当 RNG 使能（RNGEN=1）时才产生中断
- 中断状态可从 RNG_SR 寄存器读取

## RNG 处理时间 (pp.1926-1927)

### 稳态输出间隔

| 条件 | 每批 4×32bit 间隔 |
|------|------------------|
| 16× rng_clk 周期 > 213 AHB 周期 | **16× rng_clk 周期** |
| 16× rng_clk 周期 ≤ 213 AHB 周期 | **213 个 AHB 时钟周期** |

### 首次初始化时间

首次使能 RNG（RNGEN=1）后，第一笔随机数的延迟取决于两个时钟的关系：

| 条件 | 首次输出延迟 |
|------|------------|
| fAHB < fthreshold | **128** rng_clk 周期 + **426** AHB 周期 |
| fAHB ≥ fthreshold | **192** rng_clk 周期 + **213** AHB 周期 |

其中阈值频率：
```
fthreshold = (213 × fRNG) / 64
```

**举例：** 若 rng_clk = 48MHz，则 fthreshold = 213 × 48MHz / 64 ≈ 159.75MHz
- 若 AHB = 100MHz（< fthreshold）→ 首次需要 128 rng_clk + 426 AHB
- 若 AHB = 200MHz（≥ fthreshold）→ 首次需要 192 rng_clk + 213 AHB

## 寄存器 (pp.1928-1931, 37.7)

### RNG 控制寄存器 (RNG_CR)

- 偏移：`0x000`
- 复位值：`0x0000 0000`

| 位 | 名称 | 读写 | 说明 |
|----|------|------|------|
| 31:6 | - | r | 保留，必须保持复位值 |
| 5 | CED | rw | 时钟错误检测：0=使能 1=关闭。**RNG 使能时不能在线修改**，必须先关 RNG |
| 4 | - | r | 保留 |
| 3 | IE | rw | 中断使能：0=关闭 1=使能（DRDY/SEIS/CEIS 任一置位即触发中断） |
| 2 | RNGEN | rw | RNG 使能：0=关闭（模拟电源关闭，RNG 时钟门控）1=使能 |
| 1:0 | - | r | 保留 |

### RNG 状态寄存器 (RNG_SR)

- 偏移：`0x004`
- 复位值：`0x0000 0000`

| 位 | 名称 | 读写 | 说明 |
|----|------|------|------|
| 31:7 | - | r | 保留 |
| 6 | SEIS | rc_w0 | 种子错误中断状态。与 SECS 同时置位，**写 0 清除** |
| 5 | CEIS | rc_w0 | 时钟错误中断状态。与 CECS 同时置位，**写 0 清除** |
| 4:3 | - | r | 保留 |
| 2 | SECS | r | 种子错误当前状态：0=无错误/已恢复 1=检测到错误（64个连续相同位或32个连续"01""10"） |
| 1 | CECS | r | 时钟错误当前状态：0=时钟正常(fRNG>fHCLK/32) 1=时钟过慢。**仅 CED=0 时有效**。时钟恢复后硬件自动清 0 |
| 0 | DRDY | r | 数据就绪：0=RNG_DR 无效 1=RNG_DR 有有效数据。读空 FIFO 后自动清 0。**RNGEN=0 时仍可置位** |

> **SEIS/CEIS 清除特性：** 写 0 清除，写 1 无影响。

### RNG 数据寄存器 (RNG_DR)

- 偏移：`0x008`
- 复位值：`0x0000 0000`
- 只读寄存器

| 位 | 名称 | 读写 | 说明 |
|----|------|------|------|
| 31:0 | RNDATA[31:0] | r | 32 位随机数据，DRDY=1 时有效。DRDY=0 时返回 0 |

> **建议：** 即使 DRDY=1，也建议验证 RNG_DR 的值不为 0。因为轮询 RNG_SR 到读取 RNG_DR 之间可能发生种子错误（罕见），此时读到的 0 是无效数据。

FIFO 为空时，读 RNG_DR 后需要 **216 个 AHB 时钟周期**才会输出新值。

### RNG 硬件配置寄存器 (RNG_HWCFGR)

- 偏移：`0x3F0`
- 复位值：`0x0000 0000`
- 全部保留

### RNG 版本寄存器 (RNG_VERR)

- 偏移：`0x3F4`
- 复位值：`0x0000 0021`

| 位 | 名称 | 说明 |
|----|------|------|
| 7:4 | MAJREV[3:0] | 主版本号 |
| 3:0 | MINREV[3:0] | 次版本号 |

### RNG 标识寄存器 (RNG_IPIDR)

- 偏移：`0x3F8`
- 复位值：`0x0017 0041`

| 位 | 名称 | 说明 |
|----|------|------|
| 31:0 | ID[31:0] | RNG 标识码 |

### RNG 大小标识寄存器 (RNG_SIDR)

- 偏移：`0x3FC`
- 复位值：`0xA3C5 DD01`

| 位 | 名称 | 说明 |
|----|------|------|
| 31:0 | SID[31:0] | Bits[31:8]=0xA3C5DD（固定码）Bits[7:0]=0x01（1KB 地址解码） |
