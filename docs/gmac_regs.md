# GMAC 寄存器 (RM0436 Ch. 63.11)

来源: RM0436 Rev 7, 63.11 Ethernet registers, 第 3452 页起

寄存器结构: 3 个块
- 63.11.2 DMA 寄存器 (偏移 0x1000 起)
- 63.11.3 MTL 寄存器
- 63.11.4 MAC + MMC 寄存器

外设基地址: ETH1 = 0x5800_0000 (待核对), 实际地址 = 基地址 + 偏移

中断分层: ETH_DMAISR (聚合) → 各块状态寄存器 → 读源并清除

---

## 63.11.2 DMA 寄存器

通道布局: 0x1100 起每 0x80 一个通道。Tx 通道 0/1 (各一个 DMA 通道), Rx 只有通道 0。

### ETH_DMAMR — DMA 模式寄存器
- 偏移: 0x1000, 复位值: 0x0000 0000
- 功能: 建立 DMA 的总线操作模式
- 位域分布: `[31:18] Res | [17:16] INTM | [15:12] Res | [11] TXPR | [10:9] Res | [8] DSPW | [7:5] Res | [4:2] TAA | [1] Res | [0] SWR`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:18 | - | r | 保留 |
| 17:16 | INTM[1:0] | rw | 中断模式。决定中断信号行为及 ETH_DMACSR 中 RI/TI 位的响应方式 (见 Table 527) |
| 15:12 | - | r | 保留 |
| 11 | TXPR | rw | 发送优先级。置 1: 总线仲裁时 Tx DMA 优先级高于 Rx DMA |
| 10:9 | - | r | 保留 |
| 8 | DSPW | rw | 描述符 Posted Write。0: 描述符写总是非 posted; 1: 仅当最后一个描述符置 IOC 时非 posted, 其余情况 posted |
| 7:5 | - | r | 保留 |
| 4:2 | TAA[2:0] | rw | 发送仲裁算法。000: 固定优先级 (通道 0 最低, 最后通道最高); 001: 加权严格优先 WSP; 010: 加权轮询 WRR; 011~111: 保留 |
| 1 | - | r | 保留 |
| 0 | SWR | rw | 软件复位。置 1 复位 MAC+DMA+MTL 全部逻辑和内部寄存器, 复位完成后自动清 0。**重编程任何寄存器前必须读到 0**。注意: 复位完成需要所有激活时钟域的 PHY 输入时钟在场, 完成时间取决于最慢时钟 |

### ETH_DMASBMR — 系统总线模式寄存器
- 偏移: 0x1004, 复位值: 0x0101 0000
- 功能: 控制 AXI master 行为 (突发拆分、outstanding 请求数上限)
- 位域分布: `[31] EN_LPI | [30] LPI_XIT_PKT | [29:26] Res | [25:24] WR_OSR_LMT | [23:18] Res | [17:16] RD_OSR_LMT | [15:14] Res | [13] ONEKBBE | [12] AAL | [11] Res | [10] AALE | [9:8] Res | [7] BLEN256 | [6] BLEN128 | [5] BLEN64 | [4] BLEN32 | [3] BLEN16 | [2] BLEN8 | [1] BLEN4 | [0] FB`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31 | EN_LPI | rw | 使能 AXI 低功耗接口。1: 接受 AXI 系统时钟控制器的 LPI 请求; 0: 拒绝 |
| 30 | LPI_XIT_PKT | rw | 退出 LPI 条件。1: 仅收到 magic packet 或 remote wake-up packet 时退出; 0: 收到任意包即退出 |
| 29:26 | - | r | 保留 |
| 25:24 | WR_OSR_LMT[1:0] | rw | AXI 写最大 outstanding 请求数限制。最大值 = 值 + 1 |
| 23:18 | - | r | 保留 |
| 17:16 | RD_OSR_LMT[1:0] | rw | AXI 读最大 outstanding 请求数限制。最大值 = 值 + 1 |
| 15:14 | - | r | 保留 |
| 13 | ONEKBBE | rw | 1KB 边界跨越使能。1: 突发不跨 1KB 边界; 0: 突发不跨 4KB 边界 |
| 12 | AAL | rw | 地址对齐节拍。1: 读写通道执行地址对齐突发 |
| 11 | - | r | 保留 |
| 10 | AALE | rw | 自动 AXI LPI 使能。1: 外设无活动持续 ETH_DMALPIEI.LPIEI × 64 个系统时钟周期后自动进入 LPI |
| 9:8 | - | r | 保留 |
| 7 | BLEN256 | rw | 使能 AXI 突发长度 256 |
| 6 | BLEN128 | rw | 使能 AXI 突发长度 128 |
| 5 | BLEN64 | rw | 使能 AXI 突发长度 64 |
| 4 | BLEN32 | rw | 使能 AXI 突发长度 32 |
| 3 | BLEN16 | rw | 使能 AXI 突发长度 16 (FB=0 时此位无效) |
| 2 | BLEN8 | rw | 使能 AXI 突发长度 8 (FB=0 时此位无效) |
| 1 | BLEN4 | rw | 使能 AXI 突发长度 4 (FB=0 时此位无效) |
| 0 | FB | rw | 固定突发长度。1: 按 BLENx 指定长度发固定突发; 0: 突发长度 ≤ 最大允许值 (Bits[7:1] 编程值), BLEN16/8/4 无效 |

注: 手册原文 BLEN16/8/4 描述含 "set to 1 or FB=0" 的表述, 与后一句 "FB=0 时此位无效" 矛盾, 实际以 FB=1 时才生效理解。

### ETH_DMAISR — 中断状态寄存器
- 偏移: 0x1008, 复位值: 0x0000 0000
- 功能: ISR 或轮询时读取, 汇总 DMA 通道、MTL 队列、MAC 的中断状态。**只读, 清除需到对应子块读源并清**
- 位域分布: `[31:18] Res | [17] MACIS | [16] MTLIS | [15:2] Res | [1] DC1IS | [0] DC0IS`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:18 | - | r | 保留 |
| 17 | MACIS | r | MAC 中断状态。清除方法: 读 MAC 内对应寄存器找到确切原因并清源 |
| 16 | MTLIS | r | MTL 中断状态。清除方法同上 |
| 15:2 | - | r | 保留 |
| 1 | DC1IS | r | DMA 通道 1 中断状态。清除方法同上 (读 DMAC1SR 等) |
| 0 | DC0IS | r | DMA 通道 0 中断状态。清除方法同上 |

### ETH_DMADSR — 调试状态寄存器
- 偏移: 0x100C, 复位值: 0x0000 0000
- 功能: 报告通道 0/1 的 Rx/Tx DMA 进程状态, 供调试
- 位域分布: `[31:24] Res | [23:20] TPS1 | [19:16] RPS1 | [15:12] TPS0 | [11:8] RPS0 | [7:2] Res | [1] AXRHSTS | [0] AXWHSTS`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:24 | - | r | 保留 |
| 23:20 | TPS1[3:0] | r | 通道 1 Tx DMA 状态机状态 (同 TPS0) |
| 19:16 | RPS1[3:0] | r | 通道 1 Rx DMA 状态机状态 (同 RPS0) |
| 15:12 | TPS0[3:0] | r | 通道 0 Tx DMA 状态机状态: 000 停止; 001 运行 (取 Tx 描述符); 010 运行 (等状态); 011 运行 (读内存数据入 Tx FIFO); 100 时间戳写; 101 保留; 110 挂起 (描述符不可用或 Tx FIFO 下溢); 111 运行 (关闭 Tx 描述符)。最高位恒 0, 不产生中断 |
| 11:8 | RPS0[3:0] | r | 通道 0 Rx DMA 状态机状态: 000 停止; 001 运行 (取 Rx 描述符); 010 保留; 011 运行 (等 Rx 包); 100 挂起 (Rx 描述符不可用); 101 运行 (关闭 Rx 描述符); 110 时间戳写; 111 运行 (收包数据转内存)。最高位恒 0, 不产生中断 |
| 7:2 | - | r | 保留 |
| 1 | AXRHSTS | r | AXI master 读通道活跃 (正在传输数据) |
| 0 | AXWHSTS | r | AXI master 写通道活跃 |

### ETH_DMAA4TXACR — AXI4 发送通道 ACE 控制寄存器
- 偏移: 0x1020, 复位值: 0x0000 0000
- 功能: 驱动 AXI4 读事务的 arcache_m_o[3:0] 信号 (DMA Tx 通道, 按访问类型区分: 描述符/缓冲 1/缓冲 2)
- 位域分布: `[31:20] Res | [19:16] THC | [15:12] Res | [11:8] TEC | [7:4] Res | [3:0] TDRC`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:20 | - | r | 保留 |
| 19:16 | THC[3:0] | rw | 包首缓冲 / TSO 头数据访问时的 arcache 值 (TSO 未使能: TDES3.FD 置位的首个有效缓冲; TSO 使能: TSO 头数据) |
| 15:12 | - | r | 保留 |
| 11:8 | TEC[3:0] | rw | 扩展缓冲 / TSO 载荷访问时的 arcache 值 (包跨多个缓冲的后续缓冲 / TSO 载荷) |
| 7:4 | - | r | 保留 |
| 3:0 | TDRC[3:0] | rw | Tx DMA 读描述符时的 arcache 值 |

### ETH_DMAA4RXACR — AXI4 接收通道 ACE 控制寄存器
- 偏移: 0x1024, 复位值: 0x0000 0000
- 功能: 驱动 AXI4 写事务的 awcache_m_o[3:0] 信号 (Rx DMA 通道)
- 位域分布: `[31:28] Res | [27:24] RDC | [23:20] Res | [19:16] RHC | [15:12] Res | [11:8] RPC | [7:4] Res | [3:0] RDWC`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:28 | - | r | 保留 |
| 27:24 | RDC[3:0] | rw | 头/载荷未分离时, 收缓冲访问的 awcache 值 |
| 23:20 | - | r | 保留 |
| 19:16 | RHC[3:0] | rw | 头/载荷分离时, 头缓冲访问的 awcache 值 |
| 15:12 | - | r | 保留 |
| 11:8 | RPC[3:0] | rw | 头/载荷分离时, 载荷缓冲访问的 awcache 值 |
| 7:4 | - | r | 保留 |
| 3:0 | RDWC[3:0] | rw | Rx DMA 写描述符时的 awcache 值 |

### ETH_DMAA4DACR — AXI4 描述符 ACE 控制寄存器
- 偏移: 0x1028, 复位值: 0x0000 0000
- 功能: 控制 TxDMA 描述符写 / RxDMA 描述符读的 cache 信号, 以及 awprot_m_o / arprot_m_o
- 位域分布: `[31:12] Res | [11:8] RDRC | [7:6] Res | [5:4] TDWD | [3:0] TDWC`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:12 | - | r | 保留 |
| 11:8 | RDRC[3:0] | rw | Rx DMA 读描述符时的 arcache 值 |
| 7:6 | - | r | 保留 |
| 5:4 | TDWD[1:0] | rw | Tx DMA 写描述符时的 awdomain_o[1:0] 值 |
| 3:0 | TDWC[3:0] | rw | Tx DMA 写描述符时的 awcache_o[3:0] 值 |

### ETH_DMALPIEI — AXI4 LPI 进入间隔寄存器
- 偏移: 0x1040, 复位值: 0x0000 0000
- 功能: 控制 AXI LPI 进入间隔
- 位域分布: `[31:4] Res | [3:0] LPIEI`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:4 | - | r | 保留 |
| 3:0 | LPIEI[3:0] | rw | LPI 进入间隔。等待外设无活动多少系统时钟周期后进入 AXI 低功耗, 数值 × 64; 0 表示 64 个时钟周期 |

### ETH_DMACxCR — 通道 x 控制寄存器 (x = 0~1)
- 偏移: 0x1100 + 0x80 × x, 复位值: 0x0000 0000
- 功能: 指定 TSO 分段 MSS、描述符跳转长度、8xPBL 模式
- 位域分布: `[31:21] Res | [20:18] DSL | [17] Res | [16] PBLX8 | [15:14] Res | [13:0] MSS`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:21 | - | r | 保留 |
| 20:18 | DSL[2:0] | rw | 描述符跳转长度。非链式 (unchained) 描述符间跳过的 64 位字数, 从当前描述符末尾跳到下一描述符开头。0: 描述符表连续排列 (环形) |
| 17 | - | r | 保留 |
| 16 | PBLX8 | rw | 8xPBL 模式。置 1: DMACxTXCR.TXPBL / DMAC0RXCR.RXPBL 值 × 8, 支持 8/16/32/64/128/256 拍突发 |
| 15:14 | - | r | 保留 |
| 13:0 | MSS[13:0] | rw | TCP 分段最大段大小。仅当 DMACxTXCR.TSE 置位时有效, 必须大于数据总线宽度 (字节), 建议 ≥ 64 字节 |

### ETH_DMACxTXCR — 通道 x 发送控制寄存器 (x = 0~1)
- 偏移: 0x1104 + 0x80 × x, 复位值: 0x0000 0000
- 功能: 控制 Tx PBL、TCP 分段、通道权重
- 位域分布: `[31:29] Res | [28] Res | [27:24] TQOS | [23:22] Res | [21:16] TXPBL | [15] IPBL | [14:13] Res | [12] TSE | [11:5] Res | [4] OSF | [3:1] TCW | [0] ST`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:28 | - | r | 保留 |
| 27:24 | TQOS[3:0] | rw | Tx 通道 AXI QoS, 驱动 arqos_m_o / awqos_m_o |
| 23:22 | - | r | 保留 |
| 21:16 | TXPBL[5:0] | rw | 发送可编程突发长度。单次突发最大节拍数, 只能取 1/2/4/8/16/32, 其他值行为未定义。>32 拍需先置 DMACxCR.PBLX8。**上限: ≤ Tx 队列大小的一半 (4096B FIFO = 512 位置, 故 ≤ 256 拍)** |
| 15 | IPBL | rw | 忽略 PBL 要求。置 1: DMA 发起传输前不检查 MTL 中是否有 PBL 数量空间。**多通道使能时禁用** |
| 14:13 | - | r | 保留 |
| 12 | TSE | rw | TCP 分段使能。置 1: 对 TDES0[19].TSE 置位的包做 TCP 分段, 此时 TXPBL 必须 ≥ 4 |
| 11:5 | - | r | 保留 |
| 4 | OSF | rw | 第二包操作。置 1: 第一个包状态写回前就处理第二个发送包 (流水线优化) |
| 3:1 | TCW[2:0] | rw | 发送通道权重。复位后全 0 = 各通道权重相等 |
| 0 | ST | rw | 启动/停止发送命令。置 1: 进入运行态, 从 TXDLAR 基址或上次停止位置取描述符。**必须先设 TXDLAR 再置 ST**, 否则行为不可预知。清 0: 当前包传完后停止, 记住下一描述符位置, 重启时从原处继续。改列表地址需在 ST=0 时重写 TXDLAR |

### ETH_DMAC0RXCR — 通道 0 接收控制寄存器
- 偏移: 0x1108, 复位值: 0x0000 0000
- 功能: 控制 Rx PBL、缓冲大小、扩展状态
- 位域分布: `[31] RPF | [30:28] Res | [27:24] RQOS | [23:22] Res | [21:16] RXPBL | [15] Res | [14:1] RBSZ | [0] SR`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31 | RPF | rw | 包冲刷。置 1: 总线错误导致 RxDMA 停止后自动冲刷 Rx 队列中该通道的包, 重启时残留包被丢弃 (防队头阻塞); 0: 不冲刷。仅 Rx 队列与通道一一映射时有效 |
| 30:28 | - | r | 保留 |
| 27:24 | RQOS[3:0] | rw | Rx 通道 AXI QoS, 驱动 arqos_m_o / awqos_m_o |
| 23:22 | - | r | 保留 |
| 21:16 | RXPBL[5:0] | rw | 接收可编程突发长度。取值规则同 TXPBL, 上限 ≤ Rx 队列一半 (≤ 256 拍) |
| 15 | - | r | 保留 |
| 14:1 | RBSZ[13:0] | rw | 接收缓冲大小 (字节), 最大 16KB。**必须是 8 的倍数** (低 3 位硬件忽略, 只读), 否则行为未定义 |
| 0 | SR | rw | 启动/停止接收命令。置 1: 从 RXDLAR 基址或上次停止位置取描述符收包。**必须先设 RXDLAR 再置 SR**。清 0: 当前包传完后停止, 记住位置, 重启从原处继续 |

### ETH_DMACxTXDLAR — 通道 x Tx 描述符列表地址寄存器 (x = 0~1)

### ETH_DMACxTXDTPR — 通道 x Tx 描述符尾指针寄存器 (x = 0~1)
- 偏移: 0x1120 + 0x80 × x, 复位值: 0x0000 0000
- 功能: 指向相对于基址的偏移, 指示最后一个有效描述符的位置。软件写尾指针 = 给 Tx 通道添加更多描述符, 硬件传输 head 与 tail 之间所有描述符引用的包
- 位域分布: `[31:0] TDT`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:0 | TDT[31:0] | rw | Tx 描述符环尾指针。写此寄存器向硬件提交新描述符 |

### ETH_DMAC0RXDTPR — 通道 0 Rx 描述符尾指针寄存器

- 功能: 指示最后一个有效 Rx 描述符的位置。软件写尾指针添加描述符, 硬件把收到的包写入 head 与 tail 之间描述符指向的缓冲
- 位域分布: `[31:0] RDT`

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|

- 位域分布: `[31:24] Res | [23:17] ARBS | [16:10] Res | [9:0] RDRL`

| 位 | 字段 | 类型 | 含义 |

## 63.11.3 MTL 寄存器

### ETH_MACA0HR — MAC 地址 0 高寄存器

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31 | AE | r | 地址使能。**始终为 1** (地址 0 恒使能, 不可关闭) |
| 30:16 | - | r | 保留 |

### ETH_MACPPSCR — PPS 控制寄存器 (双视图)
- 偏移: 0x0B70, 复位值: 0x0000 0000

| 位 | 字段 | 类型 | 含义 |
|----|------|------|------|
| 31:7 | - | r | 保留 |
| 6:5 | TRGTMODSEL0[1:0] | rw | 目标时间寄存器 (PPSTTSR/PPSTTNR) 模式。00: 仅产生中断事件; 01: 保留; 10: 产生中断 + 启动/停止 PPS 输出; 11: 仅启动/停止 PPS 输出 (无中断) |
| 4 | PPSEN0 | rw | 灵活模式使能。1: [3:0] 作 PPSCMD; 0: [3:0] 作 PPSCTRL (固定模式) |
| 3:0 | PPSCTRL[3:0] (PPSEN0=0) | rw | PPS 输出频率控制。0000: 每秒 1 脉冲 (宽度 clk_ptp_i)。其他值: 生成时钟, 0001: binary 2 Hz / digital 1 Hz; 0010: 4/2; ... 1111: 32.768 KHz / 16.384 KHz。binary rollover: 50% 占空比; digital rollover: 平均频率, 实际时钟不均匀 (例: PPSCTRL=0001 时 1 Hz 输出低 537 ms 高 463 ms), 原因是 STNR 数字回绕的非线性翻转 |
| 3:0 | PPSCMD[3:0] (PPSEN0=1) | rw | 灵活模式命令。**编程前必须为全 0**, 命令同步到 PTP 时钟域后自动清 0。0000: 无命令; 0001: START 单脉冲 (在目标时间起, 宽度由 PPS 宽度寄存器定义); 0010: START 脉冲串 (按间隔寄存器重复, 默认自由运行); 0011: 取消 START (系统时间未过起始时间时); 0100: 按时间停止脉冲串; 0101: 立即停止脉冲串; 0110: 取消按时间停止 (脉冲串恢复自由运行); 0111~1111: 保留 |
